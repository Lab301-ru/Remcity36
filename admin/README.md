# Админка журнала · Ремсити36

Простая браузерная панель для ведения раздела **Журнал** (`/news`).
Каждая новость автоматически превращается в **отдельную SEO-страницу**
`/news/<slug>`, которую индексирует Яндекс.

## Как открыть

Откройте на сайте: **https://remcity36.ru/admin/**
Пароль входа по умолчанию: `remcity36` (меняется в `admin/index.html`, переменная `ADMIN_PASS`).

## Как добавить новость

1. Нажмите **«+ Новая новость»**.
2. Заполните: заголовок, дату, обложку (путь к картинке в репозитории, напр. `/IMG_5531.webp`),
   краткое описание (для поиска), лид и текст.
   - Текст: `## Заголовок` — новый раздел, строка `- ...` — пункт списка, пустая строка — новый абзац.
3. Вкладка **«Превью»** показывает готовую страницу.
4. **«Сохранить новость»** — сохраняет в редакторе.
5. **«🚀 Опубликовать»** — выкладывает на сайт.

## Публикация

### Вариант 1 — автоматически (рекомендуется)
В **⚙ Настройки** вставьте GitHub Personal Access Token:
- https://github.com/settings/tokens?type=beta → **Fine-grained token**
- доступ к репозиторию `lab301-ru/remcity36`
- Repository permissions → **Contents: Read and write**

После этого кнопка «Опубликовать» сама делает коммит, и сайт обновляется через ~1 минуту.
Токен хранится только в вашем браузере.

### Вариант 2 — вручную
Раздел **«Публикация без токена»** → «Скачать все файлы». Имена файлов содержат `__`
вместо `/` — восстановите структуру папок при загрузке в репозиторий.

## Что генерируется

| Файл | Назначение |
|------|------------|
| `news/posts.json` | единый источник данных (все новости) |
| `news/<slug>/index.html` | отдельная SEO-страница новости |
| `news.html`, `news/index.html` | страница-список `/news` |
| `sitemap.xml` | карта сайта со всеми новостями |
| `sw.js` | обновляется версия кэша |

## Пересборка из командной строки (для разработчика)

```bash
node admin/build.js
```

Перегенерирует все страницы из `news/posts.json`. Логика шаблонов — в `admin/generator.js`
(один и тот же код используют и браузерная админка, и скрипт сборки).
