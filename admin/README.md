# Админка журнала · Ремсити36

Браузерная панель для ведения раздела **Журнал** (`/news`).
Каждая новость автоматически становится **отдельной SEO-страницей** `/news/<slug>`,
которую индексирует Яндекс.

Архитектура построена по образцу рабочей админки lab301: вход по GitHub-токену,
визуальный редактор текста (Trix), загрузка картинок прямо в браузере со сжатием в WebP.

## Как открыть

**https://remcity36.ru/admin/** — пароля нет. При первом входе вставьте GitHub-токен
(сохраняется только в этом браузере, потом вход автоматический).

## Токен (один раз)

Подходит **любой** тип токена:

**Classic-токен** (надёжнее для репозитория организации):
- GitHub → Settings → Developer settings → Personal access tokens → **Tokens (classic)** → Generate new token
- scope **`repo`** (целиком)
- если включён SSO организации — на странице токена **Configure SSO → Authorize**

**Fine-grained токен:**
- Resource owner: **Lab301-ru** → репозиторий `remcity36`
- Repository permissions → **Contents: Read and write**
- токен должен быть **одобрен администратором** организации (иначе 403)

## Как добавить новость

1. **«+ Новая новость»**.
2. Заголовок (slug подставится сам), дата, короткое описание (для поиска), категория/тег.
3. **Обложка** — выберите фото, оно само сожмётся в WebP. Можно не добавлять.
4. **Текст** — визуальный редактор: жирный, списки, заголовки, ссылки. Картинки можно
   перетаскивать прямо в текст — они загрузятся и сожмутся автоматически.
5. **«Опубликовать»** — страница появится на сайте за ~1 минуту.

Публикация пишет напрямую в репозиторий через GitHub API (Contents): генерирует
страницу статьи `/news/<slug>/index.html`, обновляет список `/news`, `sitemap.xml`
и версию кэша `sw.js`.

## Пересборка из командной строки (для разработчика)

```bash
node admin/build.js
```

Перегенерирует все страницы из `news/posts.json`. Логика шаблонов — в `admin/generator.js`
(общая для браузерной админки и скрипта сборки). Поддерживаются и новости с готовым
HTML-телом (`bodyHtml`, из редактора), и старые структурированные (`blocks`).
